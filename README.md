# project 3: Loan Eligibility Prediction (Classification)
Part of my Data Science internship at SoftGrowTech.

## 📊 Project Overview
This project involves building a robust classification model to determine if a loan applicant is eligible for approval based on various demographic and financial factors.

## 🛠️ Tech Stack
- **Python** (Scikit-Learn, Pandas)
- **Algorithm:** Random Forest Classifier.
- **Environment:** Google Colab

## 💡 Key Results
- **Model Performance:** Achieved a test accuracy of **76.42%**.
- **Feature Engineering:** Handled categorical variables and missing data to improve model reliability.
- **Evaluation:** Analyzed results using a Confusion Matrix to track True Positives and False Negatives.
